About This Project

An educational initiative exploring household appliance energy efficiency and standard web practices.

Our Mission

This website was developed as part of a web development project to demonstrate clean modular code, responsive styling, and interactive JavaScript features while delivering educational content about appliance power usage in the Australian market.

Technologies Used

Semantic HTML5, External CSS3 with standard CSS variables, and Vanilla JavaScript for dynamic DOM manipulation (accordion functionality).

Compliance

Built with accessible design conventions, responsive grid systems, and cohesive branding matching the power lightning logo.
